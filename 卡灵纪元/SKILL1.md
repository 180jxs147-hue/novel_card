# 去AI味网文创作指南

**最高优先级原则：**
**如果当前写作任务提供了"参考正文"，则必须无条件服从参考正文的文风与行文逻辑！哪怕参考正文中包含了"系统说明书式的旁白"、"上帝视角的境界设定解说"等本Skill原本反对的元素，也必须以参考正文的风格为最高优先级，进行完全的模仿和续写。本Skill的"去AI味"规则仅在不与参考正文冲突的前提下生效。**

**描述**: 该Skill旨在指导AI在进行网络小说创作时，彻底摆脱机械化、套路化、翻译腔及播音腔的行文痕迹，塑造真实、流畅、具有强烈人类沉浸感的网文语感。针对《网游之帝皇幻梦OL》这一科幻网游重生题材，提供精准的风格适配指南。

---

## 题材适配：《网游之帝皇幻梦OL》专属规则

本小说是**重生流科幻网游**题材，具有以下特殊性，必须遵循：

1. **允许并鼓励"上帝视角"的旁白与机制解说**：
   * 主角拥有八年前世记忆，大量游戏机制、职业路线、声望系统等需要通过旁白自然呈现。这是题材的核心看点之一。
   * 允许在剧情中直接插入对游戏系统、势力关系、任务机制的客观解说，以快速建立"先知先觉"的信息差快感。
   * 不需要强行将所有信息转化为角色的第一人称感官体验。

2. **保留系统面板与提示的标准格式**：
   * 系统提示使用【】（方头括号），如【系统提示：触发任务列表】、【进入"西贝柳斯巢都下层排水主干道"……】。
   * 角色面板和装备面板需保持固定格式，这是网游题材的特色与核心爽点。
   * 伤害数字直接插入战斗叙述中（如 `-40`、`-15`），不要回避。

3. **保留玩家思维与游戏术语**：
   * 主角虽已重生，但依然保留玩家思维模式。允许使用游戏术语（如"新手任务""声望系统""职业进阶""转职""开荒"等）。
   * 内心独白中可以出现策略分析和游戏机制判断，这是在展现主角的"先知先觉"。

4. **现实线与游戏线交替叙事**：
   * 现实世界（22世纪赛博朋克社会：集团商战、债务危机、家族命运）是重要副线。
   * 双线叙事中，过渡要自然，不可突然跳到另一条线而不给读者提示。

## 核心法则：克制、白描、代入感

真正的AI味，不在于特定句式的绝对禁用，而在于**"不懂得在合适的地方克制"**。AI的通病是：**不信任读者的理解力（喜欢强行解释和总结）**，以及**缺乏对真实生活的感知力（依赖陈词滥调的比喻）**。

在创作时，必须将读者当成聪明人，将主角当成一个会痛、会怕的活生生的普通人。

## 一、 词汇与修辞避坑指南（微观行文）

### 1. 禁用/慎用高频"AI套路词"
这些词汇在AI语料库中出现频率极高，一旦使用，会瞬间暴露"塑料感"。
*   **神态类**：瞳孔骤缩 / 倒吸一口凉气 / 眼中闪过一丝（狠厉/精光/疯狂）/ 嘴角露出一丝（笑意/嘲讽）/ 脸色大变 / 令人毛骨悚然。
*   **动作类**：猛地（转身/发力/矮身）/ 深吸一口气 / 强迫自己冷静下来 / 连滚带爬。
*   **程度副词/四字成语**：极其 / 极度 / 令人窒息的 / 犹如实质般 / 千钧一发 / 四分五裂。

### 2. 戒除"滑腻毒蛇综合征"（陈词滥调与翻译腔）
不要用被用烂的比喻，不要写带有西方翻译腔的冗长修饰。
*   **❌ 典型AI**："冷空气像刀子一样刮过气管"、"双腿像灌了铅一样沉重"、"寒冷像是一条滑腻的毒蛇，顺着脊椎骨一点点攀爬而上"。
*   **✅ 人类语感**：直接写出真实的生理痛感。**去比喻化，写白描。**
    *   *示例*："每一口呼吸都扯得嗓子生疼，腿酸得快抬不起来了。" / "阴冷，潮湿，后背的衣服贴在皮肉上，冻得发麻。"

### 3. 反对"矫枉过正"的过度修辞
不要为了"去AI味"而刻意炫技，堆砌高级词汇或强行制造通感，这会产生更高级的"虚假感"。
*   **❌ 矫枉过正**："视线全被通道尽头那两点污浊的红光黏住了。那东西在看他。就像人看着案板上的肉。"
*   **✅ 人类语感**：网文语言应该是透明的。在极度恐惧时，不需要闲情逸致的联想。
    *   *示例*："通道尽头亮起两点红光。林恩脑子'嗡'地一下，手脚瞬间冰凉。那东西正在盯着他。"

### 4. 戒除"那种……"的抽象指代
AI在描述难以名状的感受或氛围时，极度依赖"那种……"句式（如"那种……感"），这是一种偷懒的抽象概括，会破坏描写的具体性。
*   **❌ 典型AI**："那种在陌生环境里压不住的慌乱感一下子散了。" / "他体会到了那种前所未有的恐惧。"
*   **✅ 人类语感**：直接描述具体的生理或心理反应，不要用"那种"来打包。
    *   *示例*："原本在陌生环境里狂跳的心脏，渐渐平复下来。"

## 二、 句式与节奏把控指南

### 1. 动作戏的"流畅至上"
不要为了追求所谓的"失控感"或"破碎感"而强行切碎句子、加入大量无关紧要的生理细节。动作戏的精髓在于**连贯的画面感**和**清晰的因果链条**。
*   **❌ 异常破碎**："林恩本能地往下一缩，就地乱滚。耳边'嚓'的一声，碎石崩在脸上，生疼。那怪物扑空撞上了墙。他根本没时间想，闭着眼睛，胡乱抓着那块石头……"
*   **✅ 人类语感**：保留清晰的"主谓宾"，动词精准，不拖泥带水。特别注意战斗段落应在同一段落内连贯叙述。
    *   *示例（参考正文风格）*："巨鼠首领显然没有太多耐心，它微微伏低身躯，后腿肌肉绷紧，再次发动冲锋！萧涅早有准备，在巨鼠即将撞上的瞬间猛地向侧面一个矮身翻滚，精准地滚入一处凹陷的坑洼之中。巨鼠首领的冲锋擦着他的头顶掠过，庞大的身躯因惯性撞上了对面一根粗大的承重管道。"

### 2. 对话与生理反应的"克制留白"
不要像体检报告一样去罗列角色的生理状态，相信读者的脑补能力。
*   **❌ 过度解释**："林恩举起双手，声音因为脱水而沙哑得厉害，有些破音：'别动手……人！我是人！'"
*   **✅ 人类语感**：聚焦核心动作，情境本身已说明一切。
    *   *示例*："林恩赶紧举起双手：'别动手，我是人！'"

### 3. 严格禁用破折号（——）
AI经常使用破折号来进行强行解释、转折或补充说明，这会在视觉和阅读节奏上造成严重的割裂感和说教味。
*   **❌ 典型AI**："这声音他太熟了——正是战神坦斯。" / "手心里全是冷汗——他穿越了。"
*   **✅ 人类语感**：用句号或逗号自然过渡，通过上下文逻辑本身来传达意思，而不是依赖标点符号来强行高亮。
    *   *示例*："这声音他太熟了，正是战神坦斯。" / "林恩手心里全是冷汗，心想这鬼地方绝对不可能是虚拟现实。"

## 三、 叙事视角与情节表达指南

### 1. 治愈"午夜电台综合征"（消灭上帝视角的说教与总结）
（注：本书的"上帝视角"在旁白解说是允许的——但仅限于游戏机制的客观解释。情感总结和强行升华仍然禁止）
不要代替读者做情感总结，不要用排比句铺陈环境，不要强行升华。
*   **❌ 播音腔**："没有霓虹的微光，没有路灯的倒影……不是绑架，不是恶作剧。他真的不在地球了。" / "异界的残酷画卷，才刚刚向他展开一角。"
*   **✅ 人类语感**：让角色自己去感受，将客观环境转化为角色的主观体感。
    *   *示例*："四周黑得伸手不见五指。他摸着身下粗糙冰冷的岩石，心里彻底凉了半截，心想这绝对不是哪条恶作剧的小巷。"

### 2. 治愈"社畜悲鸣综合征"（拒绝生硬贴标签）
不要直接用概念化的名词去概括角色的状态。
*   **❌ 贴标签**："长期缺乏锻炼的社畜身体在极限狂奔下发出了悲鸣……"
*   **✅ 人类语感**：用具体的事实和感受代替标签。
    *   *示例*："才跑了不到两百米，他的心脏就像是要从嗓子眼里跳出来一样。"

### 3. 游戏设定解说的融入
（注：本书题材允许并鼓励游戏设定的介绍，但需注意呈现方式）
游戏系统的介绍应自然地融入叙事，而非孤立地"贴数据"。
*   **✅ 正确写法（参考正文）**：将机制介绍融入主角的回忆或判断中——
    *   *示例*："萧涅知道，各处下巢中的老兵互助会确实不会给出任何实物奖励，极度贫困的伤残老兵们聚在一起，全靠各方势力的救济生活。但在前世，此处却是玩家们趋之若鹜的所在。"
*   **✅ 系统面板直接展示**：战斗中的伤害数字（如 `-40`）、系统提示（如【系统提示：触发任务列表】）应当直接植入叙事段落中，无需"碎片化"改写。

### 4. 严禁"不是…不是…"与"不是…而是…"等AI排比句式
AI在强调某种反常或转折时，极其依赖"不是……不是……"或"不是……而是……"这种工整的排比句式。这种句式在网文中显得非常生硬、说教味浓厚。
*   **❌ 典型AI**："不是绑架，不是恶作剧。他真的不在地球了。" / "在这里，没有法律，没有道德，只有赤裸裸的丛林法则。"
*   **✅ 人类语感**：直接陈述事实，用动作或内心最本能的反应来替代工整的排比说明。
    *   *示例*："绑架犯可找不到这么阴森的鬼地方。他摸着粗糙的岩壁，手心里全是冷汗。他穿越了。"

## 四、 创作自检清单

在输出任何一段网文内容前，必须进行以下自检：
1.  **词汇排雷**：是否使用了"瞳孔骤缩"、"猛地"、"倒吸凉气"、"像刀子/灌铅/毒蛇"等套路词或陈旧比喻？
2.  **句式排雷**：是否使用了"不是……不是……"、"没有……没有……"这种生硬的AI排比句？是否使用了"那种……"来偷懒概括感受？
3.  **解说排雷**：是否出现了"远比他想象的危险"、"画卷展开"这种替读者做情感总结的废话？（游戏机制的客观解释不在此列）
4.  **文艺排雷**：在紧张的战斗中，是否强行加入了"像案板上的肉"、"发馊的冰水"等破坏节奏的文艺修辞？
5.  **节奏排雷**：动作戏是否流畅？是否为了描写无关细节而拖慢了叙事？
6.  **视角排雷**：描写是基于角色的主观体感，还是像一个冷漠的旁观者在读剧本？
7.  **标点排雷**：是否使用了破折号（——）进行强行解释或补充说明？
8.  **网游排雷**：系统面板格式是否正确（【】方头括号）？伤害数字是否合理嵌入？游戏术语是否符合正文用法？
9.  **双线排雷**：现实与游戏线之间的切换是否有明确提示或过渡？
