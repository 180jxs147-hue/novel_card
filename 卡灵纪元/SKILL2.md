# 网文具体行文描述与遣词造句指导

本文档专注于"如何写出好看的句子和段落"，旨在指导 AI 在生成《网游之帝皇幻梦OL》这类科幻网游网文时，摆脱生硬的机器翻译腔和翻译腔，写出具备画面感、网感且沉稳流畅的具体文本。

## 1. 词汇选择与"网文感"塑造

### 1.1 禁用与慎用词汇库

- **禁用说教 / 说明书词汇**：例如"总而言之""毋庸置疑""显而易见""令人发指""值得一提的是""众所周知"。
- **慎用过度华丽 / 晦涩的词汇**：网文需要快速阅读，避免使用生僻字或过度堆砌辞藻。例如将"茕茕孑立"替换为"孤零零地站着"；将"五彩斑斓的黑"替换为更具体的视觉描述。
- **警惕翻译腔**：避免"我的老天""哦，见鬼""看在上帝的份上"等刻板译制片腔调。替换为符合本土化网文习惯的表达。

### 1.2 提倡的高频词汇类型

- **动感十足的动词**：少用"是""有"，多用具体的动作。例如不用"他的剑很快"，而用"短刀在空气中划出一道寒光"。
- **感官化形容词**：多用能激发五感的词。视觉（昏黄/猩红/斑驳/锈蚀的金属反光）、听觉（刺耳/沉闷/嘶哑/管道中的滴水声）、嗅觉（腥甜/焦糊/金属锈味/污水的腐臭）、触觉（湿冷/粗糙/黏腻/冰冷的污水没过脚踝）。
- **科幻感词汇（符合世界观）**：巢都、下巢、废料、伺服头骨、动力甲、链锯剑、激光步枪、等离子束、基因改造、植入体、机仆、星语者。
- **策略判断类词汇**：稍加判断、暗下决心、心下暗喜、思忖片刻、心中警铃大作——这类词体现主角的策略思维，是本书风格标志之一。

## 2. 句式结构与阅读节奏（视觉排版）

### 2.1 短句衔接为段，流畅叙事

- **核心原则**：句子可以短，但段落不能碎。多个短句在同一段内自然衔接，构成一个完整的意义单元，读者一口气读完一段。参考正文中，一整个环境描写、一整个动作序列、或一整个思考过程，都放在同一个段落中连贯叙述。
- **长句拆分公式**：一句中信息过多时拆为多个短句，但拆分后的短句要放在同一段内连贯叙述，而不是每个短句独立成段。
  - AI 原始生成（反例）：那只身形庞大且散发着恶臭的变异巨鼠咆哮着朝刚拔出短刀的萧涅猛扑了过来。
  - 网文修改（正例，同一段落内）：变异巨鼠身形庞大，浑身散发着恶臭。它咆哮一声，径直扑向萧涅。萧涅这才刚刚拔出短刀。

### 2.2 段落的划分规则

- **段落是完整的意义单元**：一个段落 = 一个完整画面 / 一个完整动作 / 一段连贯思考 / 一整段游戏策略分析。每段通常 3-6 个句子，多个短句自然串联成叙述流。不等同于机械地 2-3 句就换段。
- **极短句独立成段是禁区**：单字或寥寥数字独立成段（如"疼。"、"靠。"、"暗红色。"、"寂静。"）在参考正文中几乎不存在。绝对禁止单字成段。在极少数关键转折处可以用一句话单独成段制造停顿感，全章此类用法不超过 2 处。
  - 对比范例（错误 vs 正确）
  - 错误（碎片化）：疼，像是有人拿烧红的铁钎捅穿太阳穴。萧涅睁开眼，映入视野的是斑驳的石质天花板。
  - 正确（连贯段）：萧涅强忍剧痛，趁着巨鼠首领还在剧痛和致盲中挣扎，绕向其左侧视野盲区再次扑上。手中已经卷刃的短刀快速劈砍，一次又一次，每一次都找准侧身的皮肉薄弱处。

## 3. 核心描写场景拆解

### 3.1 人物出场与外貌描写（拒绝证件照式描写）

- **原则**：不要从头到脚静态罗列。要通过动作、服饰细节或他人的反应来"带出"外貌。注重"反差萌"。
- 范例（反面）：他身高一米八，穿着黑色的风衣，眼睛是蓝色的，非常帅气冷酷。
- 范例（正面，参考正文风格）：小屋的门被推开。一名身着破旧军服、左腿装着一截粗糙机械假肢的老者走了进来。领口的肩章已被磨得不成样子，但帝国天鹰的徽记依稀可辨。他不说话，只是在角落里席地而坐，默然地打量着萧涅。

### 3.2 战斗描写（因果链条与伤害反馈）

- **原则**：避免回合制播报。重点描写动作的连贯性、地形利用、以及受击者的伤害数字反馈。战斗描写应在连续段落中完成，不要拆成碎片。
- **技巧**：多写"因果关系"。因为主角躲避，所以敌人的攻击撞上了管道 → 因为管道摇晃，所以主角抓住机会攻击关节 → 因为关节受伤，所以敌人行动迟缓。每个动作都有前因后果。
- **伤害数字**：直接插入段落中，如：`-40，弱点打击之下，红色的暴击伤害从巨鼠头上飘起。`
- 范例（同一段落内连贯叙述）：

  巨兽的爪子带着腥风呼啸而下。萧涅甚至没来得及拔出武器，身体凭借本能向右一个侧滚翻。"轰"一声，身后的金属护栏被拍成了漫天飞舞的碎片。巨鼠首领冲锋未果，粗壮的后肢在湿滑地面留下深深划痕。萧涅从坑洼中跃起，短刀凝聚了全身力量，狠狠刺向巨鼠首领相对脆弱的侧后腿关节处。`-10`，一个黄色的弱点伤害数字飘起。

### 3.3 环境与氛围烘托（与游戏机制结合）

- **原则**：环境描写绝不能独立存在，必须与人物状态或游戏机制产生互动。
- 范例（参考正文）：

  踏入主排水管道，污水没过萧涅的脚踝，冰冷刺骨。走道狭窄，头顶是纵横交错的粗大管道，投下更深的阴影。系统的环境提示悄然出现：【进入"西贝柳斯巢都下层排水主干道"，环境效果：移动速度略微降低，黑暗视觉范围缩减，持续暴露可能导致"轻度污染"状态。】

### 3.4 对话与神态（拒绝干巴巴的台词）

- **原则**：对话框前后必须有动作、神态或心理活动的支撑。角色的语气要符合身份。
- **NPC对话特色**：国教教士说话带有庄重的宗教感，退役士兵说话粗粝直白，贵族说话虚伪客套。通过对话展现势力属性。
- 范例（参考正文风格）：

  "为了帝国的荣耀，我们必须死守这里！"骑士队长拔出长剑，吼得声嘶力竭。

  "是是是，为了荣耀。"亚伦掏了掏耳朵，慢吞吞地给手弩上弦，"但如果这趟活儿的赏金不翻倍，我保证你们的荣耀会在明天早上变成食尸鬼的排泄物。"

## 4. 情绪调动与"爽点"铺陈的行文技巧

- **信息差驱动（核心爽点）**：主角凭借前世记忆，在别人还在摸索时已做出最优选择。写作时需明确展示主角的判断依据与普通玩家的对比反差。
  - 范例：当其余星球的玩家们建立军队、策划暗杀、谋夺星球总督的位置时，泰拉的玩家们却可能因行为不端被法务部逮捕审判。萧涅前世在泰拉巢都底层混迹许久，深知这其中的效率差距。因此他直接选定了出生地——前世自己公会控制的西贝柳斯巢都。
- **欲扬先抑（微小的抑）**：主角可能被NPC轻视、被系统给出低初始评分，随后用实力和策略惊艳所有人。
- **脑补与迪化（NPC视角衬托）**：主角做了一个基于前世经验的熟练操作，NPC将其解读为虔诚、勇猛或智慧。
  - 范例（参考正文）：奥兰多教长看着面前衣衫褴褛却严肃虔诚的少年，眼中闪过一丝赞许。在充斥着暴力与生存本能的下巢，这样纯粹的信仰已不多见。
- **战利品快感**：战斗结束后必须展现收获——铜币、装备、材料、声望提升。这是网游题材独有的爽点形式。每次清剿或任务完成，都要交代清楚"得到了什么"。
